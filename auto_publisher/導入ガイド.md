# 自動出品ツール 導入ガイド（はじめにお読みください）

ご購入ありがとうございます。このツールは、商品データ（CSV）を
**自分のショップの出品フォームに自動入力**してくれるRPAツールです。

このファイルの通りに進めれば、PCに詳しくなくても使えます。
所要時間：初回セットアップ 15〜30分。

---

## ⚠️ 最初に必ず確認（とても大事）

- **自分のショップ・自分の商品にのみ**使ってください。
- 推奨の出品先＝**自分の店として使えるデジタル販売所**（BOOTH / BASE / STORES / Gumroad など）。
- **メルカリ・ラクマ等は使わないでください**。これらは自動化（ツール利用）を
  規約で禁止しており、アカウント停止のリスクがあります。
- 連続で大量に出品しないでください（ツールにも上限・待機の安全装置が入っています）。

---

## ステップ0：用意するもの
- パソコン（Windows または Mac）
- 出品したいデジタル商品ファイル
- 出品先ショップのアカウント（無料でOK）

---

## ステップ1：Python を入れる（初回のみ）
1. https://www.python.org/downloads/ を開く
2. 「Download Python」ボタンで最新版をインストール
   - **Windowsの方は、インストール画面で「Add Python to PATH」に必ずチェック**
3. インストール後、「ターミナル」(Mac) /「コマンドプロンプト」(Windows) を開いて
   次を入力し、バージョンが表示されればOK：
   ```
   python --version
   ```

## ステップ2：ツールの準備（初回のみ）
ターミナルで、このフォルダに移動してから順に実行します。
（フォルダへの移動は `cd ` の後にフォルダをドラッグ＆ドロップすると楽です）

```
pip install -r requirements.txt
python -m playwright install chromium
```

## ステップ3：出品先の設定
1. `config.example.yaml` をコピーして `config.yaml` という名前にする
2. `config.yaml` をメモ帳などで開き、次を埋める：
   - `login_url`：出品先のログイン画面のURL
   - `listing_url`：新規出品フォームのURL
   - `fields` の `selector`：各入力欄の「CSSセレクタ」
     - 出品フォームを開き、入力欄を右クリック →「検証」→ 反転した部分を
       右クリック →「Copy」→「Copy selector」で取得できます
   - `submit_selector`：出品ボタンのセレクタ
3. `products.csv` に出品したい商品を1行ずつ書く（見本が入っています）

> セレクタの取得が難しい場合は、まず1項目（商品名だけ）から始めると安心です。

## ステップ4：まず「下見」する（ブラウザを起動しない安全確認）
```
python run.py --plan
```
→ どの欄に何を入れる予定かが文字で表示されます。内容を確認。

> ⚠️ **ログインは「メールアドレス＋パスワード」で。**
> 「Googleでログイン」などのソーシャルログインは、自動操作のブラウザだと
> プロバイダ側（Google等）にブロックされます。これはどの自動化ツールでも共通です。
> パスワード未設定の場合は、先に普段のブラウザでアカウント設定から設定してください。

## ステップ5：確認モードで動かす（出品はしない）
```
python run.py
```
→ ブラウザが開きます → **手動でログイン** → ターミナルで Enter
→ 各商品がフォームに自動入力されます（**出品ボタンは押されません**）。
動きと入力内容が正しいか目で確認してください。

## ステップ6：本番出品
確認できたら：
```
python run.py --live
```
→ 同じ流れで、今度は実際に出品まで行います。

---

## うまくいかないとき（トラブル対処）
| 症状 | 対処 |
|---|---|
| `python` が見つからない | ステップ1をやり直し（WindowsはPATHのチェック必須） |
| `pip` でエラー | `python -m pip install -r requirements.txt` を試す |
| 入力欄に入らない | セレクタが違う可能性。検証で取り直す。サイト更新で変わることも |
| ログインが毎回必要 | `config.yaml` の `user_data_dir` フォルダを消さないこと |
| 速すぎて怖い | `min_delay_sec` / `max_delay_sec` を大きくする |

---

## 安全装置のまとめ（config.yaml の safety）
- `dry_run: true`：出品ボタンを押さない確認モード（`--live`で解除）
- `max_per_run`：1回の出品上限
- `min/max_delay_sec`：操作のランダム待機
- `user_data_dir`：ログイン状態を保存（ID/パスワードは保存しません）
