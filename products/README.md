# products ―― 実際に売るデジタル商品

「ツールはあるが売り物がない」状態を埋めるためのフォルダです。
ここに**そのまま販売できる商品**と、**出品ページに貼る販売コピー**を入れています。

## 中身
```
products/
├── README.md                       # このファイル
├── sales_copy.md                   # 3商品ぶんの販売用テキスト（コピペで出品）
└── 01_automation_prompts/
    └── 業務自動化プロンプト集.md      # 実物の商品①（40本以上のプロンプト）
```

## 売る3商品
| # | 商品 | 実体 | 想定価格 |
|---|---|---|---|
| 1 | 業務自動化プロンプト集 | `01_automation_prompts/` のMarkdown | ¥980〜2,980 |

## 全体の流れ（このリポジトリ3点セット）
```
[商品を作る] products/            ← 売り物（このフォルダ）
      │
      ▼ 出品
[出品を自動化] auto_publisher/    ← 自分のショップに自動出品
      │
      ▼ 集客
[記事で集客]  seo_autopilot/      ← SEO記事を量産して見込み客を集める
```

## まず何をするか（最短ルート）
1. `01_automation_prompts/業務自動化プロンプト集.md` を**自分で一度読んで加筆・調整**
   （体験談や自分のジャンル向けプロンプトを足すほど価値が上がる）
2. note か BOOTH の無料アカウントを作る
3. `sales_copy.md` の「商品1」のタイトル・説明をコピペして **¥980で出品**
4. 売れたら値上げ＆商品2・3を追加 → `auto_publisher` で複数ショップへ横展開
