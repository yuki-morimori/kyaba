# 商品ラインナップ設計 ―― 1エンジンから複数の格安ツールを量産する

`auto_publisher` は本質的に「**CSV → Webフォームに自動入力**」するエンジンです。
コードは1つのまま、**設定ファイル(config)とCSVの列、販売文だけを変える**ことで、
別商品として何種類も売れます。これが格安ツール量産の核です。

```
        ┌─ config.booth.yaml  → 「BOOTH自動出品ツール」
1つの   │─ config.form.yaml   → 「フォーム自動記入ツール」
エンジン ┤─ config.〇〇.yaml   → 「△△一括登録ツール」…
        └─ （設定とCSVと販売文を変えるだけ）
```

## 売る商品の一覧（案）

| # | 商品名 | 使う設定 | 用途 | 価格 |
|---|---|---|---|---|
| A | BOOTH自動出品ツール | `config.booth.yaml` | 自分の店に商品を一括出品 | ¥1,000 |
| B | Webフォーム自動記入ツール | `config.form.yaml` | 申込/登録/応募/問合せをCSVから一括入力 | ¥1,000 |
| C | 複数ショップ一括出品ツール | 複数config | BOOTH＋BASE＋STORESへ横展開 | ¥2,980 |
| D | 自動入力ツール詰め合わせ | A+B+C | セット販売（割安感を出す） | ¥3,980 |
| E | 業務自動化プロンプト集 | （データ商品） | AI活用テンプレ | ¥980 |
| F | Claude Code SEO自動運転 | `seo_autopilot` | 記事量産・集客 | ¥3,980 |

> ポイント：**中身（エンジン）はA〜Dで共通**。違うのは config と CSV のサンプル、
> そして販売ページの「タイトル・説明・サムネ」だけ。労力を増やさず商品数を増やせる。

## 量産の手順（新商品を1つ増やすとき）
1. 用途に合う `config.〇〇.yaml` を1枚用意（既存をコピーして書き換え）
2. その用途のサンプルCSV（列名を合わせる）を1つ用意
3. `build_windows.ps1` の同梱configを差し替えてビルド → 専用zip完成
4. `sales_copy.md` を参考に、その用途向けの販売文を書く
5. 出品（まず¥1,000）

## 売り方の戦略
- **入口は¥1,000の単品**（AかB）でレビューと実績を作る
- 慣れたら **セット商品D（¥3,980）** に誘導して単価アップ
- 「○○の作業が自動になる」と**用途を具体的に**書くほど刺さる
  （「自動出品」より「BOOTHの出品入力が3クリックで終わる」のように）
- 各商品の説明に「他にもこんな自動化ができます」と**回遊**を作る

## 注意（全商品共通）
- 各サイトの規約・法令の範囲で。自動化禁止のC2C（メルカリ等）は対象外。
- フォーム仕様の変更で動かなくなることがある旨を明記（セレクタ調整で対応）。
- 「PCで簡単な操作ができる方向け」等、前提を正直に書く（クレーム予防）。
