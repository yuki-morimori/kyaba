# 業務自動化プロンプト集 ―― コピペで使える実践テンプレート

AI（ChatGPT / Claude など）に貼り付けて、`{{ }}` の中を自分の情報に差し替えるだけで
使える実務プロンプト集です。カテゴリ別に整理しています。

**使い方**
1. 使いたいプロンプトをまるごとコピー
2. `{{ }}` の箇所を自分の状況に置き換え
3. AIに貼り付けて実行 → 出力を確認して微調整

> ヒント: 最初に「あなたは〇〇の専門家です」と役割を与えると精度が上がります。
> 出力が長すぎる/短すぎるときは「300字以内で」「箇条書きで」と指定を足してください。

---

## 1. メール・連絡

### 1-1. ビジネスメールを一発作成
```
あなたは丁寧で簡潔なビジネスメールを書くアシスタントです。
次の条件でメール本文を作成してください。

宛先（関係性）: {{例: 取引先の担当者、初めての連絡}}
目的: {{例: 打ち合わせの日程調整}}
盛り込む情報: {{箇条書きで。日時候補、資料の有無など}}
トーン: {{例: 丁寧／カジュアル}}

件名も付けてください。冗長な前置きは省き、相手がすぐ返信できる形にしてください。
```

### 1-2. 返信の下書き（受け取ったメールに返す）
```
次の受信メールに対する返信を作成してください。

【受信メール】
{{受け取ったメールを貼り付け}}

【こちらの意図】
{{例: 提案は受けるが、納期を1週間延ばしたい}}

角を立てず、要点が明確な返信にしてください。件名は「Re:」で。
```

### 1-3. 催促・リマインドを angに なりすぎず
```
次の件について、相手を不快にさせない催促メールを作ってください。

相手: {{関係性}}
催促する内容: {{例: 先週依頼した見積もりの返答}}
締め切り: {{あれば}}

「お忙しいところ恐れ入りますが」など、相手を立てる表現を使ってください。
```

## 2. 営業・提案

### 2-1. 提案の骨子を作る
```
あなたは経験豊富な営業担当です。次の商談に向けた提案の骨子を作ってください。

商品/サービス: {{自社の商品}}
相手の業種・規模: {{例: 従業員20名の製造業}}
相手の課題（仮説）: {{分かる範囲で}}

「相手の課題 → 解決策 → 導入効果 → 次のアクション」の流れで、
箇条書きの骨子にしてください。専門用語は避けてください。
```

### 2-2. 想定問答（よくある反論への切り返し）
```
次のサービスを売る際に、見込み客から出そうな反論・懸念を5つ挙げ、
それぞれに対する誠実な切り返しトークを作ってください。

サービス: {{内容と価格}}
ターゲット: {{誰向けか}}

煽らず、相手の不安に共感したうえで根拠を示す形にしてください。
```

### 2-3. フォローアップ文面
```
商談後のフォローアップメッセージを作ってください。

商談の概要: {{何を話したか}}
相手の反応: {{前向き／検討中 など}}
次に促したい行動: {{例: 無料トライアルの申込}}

押し売りにならないトーンで、価値を再確認させる内容にしてください。
```

## 3. ライティング・コンテンツ

### 3-1. ブログ記事の構成案
```
次のキーワードで検索する人の意図を分析し、SEO記事の構成案（H2/H3）を作ってください。

キーワード: {{例: 〇〇 始め方}}
読者: {{誰が何のために検索するか}}

各見出しで「読者のどの疑問を解決するか」も一言添えてください。
```

### 3-2. 文章のトーン変換
```
次の文章を、指定したトーンに書き換えてください。意味は変えないこと。

【元の文章】
{{貼り付け}}

【変換後のトーン】: {{例: もっとカジュアルに／専門的に／簡潔に}}
```

### 3-3. キャッチコピーを10案
```
次の商品/サービスのキャッチコピーを10案作ってください。

商品: {{内容}}
ターゲットが感じている悩み: {{あれば}}

短く（20字以内）、ベネフィットが伝わる案を中心に。
方向性の違う案（感情的／論理的／数字訴求など）を混ぜてください。
```

## 4. 要約・議事録

### 4-1. 長文を3行に要約
```
次の文章を、要点を落とさずに3行で要約してください。
その後に、重要キーワードを5つ挙げてください。

【文章】
{{貼り付け}}
```

### 4-2. 議事録を整形
```
次の打ち合わせメモを、読みやすい議事録に整形してください。

【メモ】
{{箇条書きや走り書きを貼り付け}}

出力は「決定事項」「ToDo（担当・期限つき）」「保留・論点」の3区分にまとめてください。
```

### 4-3. 文字起こしから要点抽出
```
次の文字起こしから、重要な発言・決定・次のアクションだけを抽出してください。
雑談や言い直しは省いてください。

【文字起こし】
{{貼り付け}}
```

## 5. データ・リサーチ

### 5-1. 表データを分析
```
次のデータを見て、気づいた傾向・異常値・示唆を箇条書きで挙げてください。
その後、次に取るべきアクションを3つ提案してください。

【データ】
{{表やCSVを貼り付け}}
```

### 5-2. 比較表を作る
```
次の選択肢を、指定した観点で比較する表（Markdown）を作ってください。

選択肢: {{A, B, C}}
比較の観点: {{例: 価格・機能・サポート・向いている人}}

最後に「どんな人にどれが向くか」を一言ずつ添えてください。
```

### 5-3. リサーチの観点出し
```
{{調べたいテーマ}}について調べる前に、押さえるべき観点・問いを10個リストアップしてください。
初心者が見落としがちな点も含めてください。
```

## 6. 企画・アイデア

### 6-1. アイデアを量産
```
{{テーマ}}に関するアイデアを20個出してください。
ありきたりなものだけでなく、少し変わった切り口も混ぜてください。
各案は1行で簡潔に。
```

### 6-2. 企画を1枚にまとめる
```
次のアイデアを、企画書の骨子（1枚）にまとめてください。

アイデア: {{ざっくり書く}}

「目的 / ターゲット / 提供価値 / 必要なもの / 想定リスク / 最初の一歩」の項目で。
```

### 6-3. ネーミング案
```
次のものの名前の候補を15個出してください。

対象: {{サービス／商品／企画}}
イメージ: {{例: 親しみやすい／高級感}}

覚えやすさ重視で。読み方も添えてください。
```

## 7. SNS・発信

### 7-1. X(旧Twitter)投稿を量産
```
次のテーマについて、X用の投稿を5案作ってください。

テーマ: {{伝えたいこと}}
ターゲット: {{誰に届けたいか}}

140字以内、最初の1行で目を止める書き出しに。煽りすぎず、保存したくなる内容で。
```

### 7-2. ショート動画の台本
```
次のテーマで、30秒のショート動画（縦型）の台本を作ってください。

テーマ: {{内容}}

「最初の3秒のフック → 本題 → 締め(行動喚起)」の構成で。
画面に出すテロップ案も付けてください。
```

### 7-3. 発信ネタを30個
```
{{あなたの専門・発信ジャンル}}で、フォロワーが反応しやすい発信ネタを30個出してください。
「悩み解決系」「意外な事実」「失敗談」などタイプを散らしてください。
```

## 8. コード・自動化

### 8-1. 作業を自動化するスクリプトの相談
```
次の手作業を自動化したいです。実現方法の選択肢と、おすすめを教えてください。

やりたいこと: {{例: フォルダ内の画像を一括リサイズ}}
今の環境: {{Windows/Mac、使えるツール}}

初心者でも実行できる手順で、コードが必要ならコメント付きで書いてください。
```

### 8-2. エラーの原因を調べる
```
次のエラーが出ています。原因と直し方を、初心者にも分かるように説明してください。

【エラー全文】
{{貼り付け}}

【やろうとしていたこと】
{{状況}}
```

### 8-3. 表計算の関数を作る
```
次の処理を行うスプレッドシート/Excelの数式を作ってください。

やりたい処理: {{例: A列が「完了」の行のB列を合計}}
使うソフト: {{Googleスプレッドシート / Excel}}

数式と、その意味の説明を付けてください。
```

## おまけ：精度を上げる「魔法の追記」集

プロンプトの最後に足すと出力が良くなる一文です。

- `ステップごとに考えてから答えてください。`
- `専門用語は使わず、中学生にも分かるように説明してください。`
- `まず質問の意図を確認し、不明点があれば質問してから答えてください。`
- `3つの案を出し、それぞれの長所短所を添えてください。`
- `出力は{{Markdown / 表 / 箇条書き}}形式で。`
